### About

I'm interested in making software more reliable and efficient with AI.

- **AI for software engineering** — agents that understand, reason about, and improve code.
- **Formal methods** — specifications, program reasoning, and correctness.
- **Bug finding & debugging** — using LLMs to locate bugs and understand their root causes.
